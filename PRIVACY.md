# KDex Agent - Privacy Policy

Last updated: 2026-11-11

KDex Agent is a chat app that can work inside a folder you choose on your phone. It has no server and no user accounts.

## What stays on your phone
- Your chats, memory notes, settings, usage numbers and file backups are stored only on your device.
- Your API keys and Git access tokens are stored encrypted with the Android Keystore. They are never sent to us.
- Git data (commit history of repositories you clone or create) is stored inside the app.

## What leaves your phone
- When you send a message, the text, any attached files or images, and any file contents the assistant reads from your chosen folder are sent directly to the AI provider you configured (for example Anthropic, OpenAI, DeepSeek, OpenRouter or a custom endpoint). Their privacy policies apply to that data.
- When you use Git, requests go to the Git host you enter (for example GitHub or GitLab) with your token.
- We do not receive, collect, sell or share any of this data. We run no analytics and no advertising.

## Folder access
The app reads or changes files only inside the folder you pick through Android's folder picker, and only when you ask. Every change needs your approval unless you turn on automatic apply, and a backup is saved before each change. You can remove the folder at any time in Projects.

## Reporting content
AI replies can be wrong or inappropriate. Use the flag button under a reply to report it.

## Your control
Delete a chat in the chat list, remove a provider or token in Settings, or uninstall the app to delete everything the app stores.

## Children
The app is not directed to children under 13.
